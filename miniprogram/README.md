# 微信引流小程序

最简单的微信引流小程序：展示微信二维码 + 微信号复制按钮，用户打开后长按识别加微信。

## 功能

- 展示微信二维码（支持长按识别）
- 显示微信号，一键复制
- 保存二维码到相册
- 紫色渐变背景，简洁美观

## 使用步骤

### 第 1 步：注册微信小程序

1. 打开 https://mp.weixin.qq.com
2. 点「立即注册」→ 选「小程序」
3. 用邮箱注册，选择「个人」主体（免费，不需要营业执照）
4. 完成实名认证（身份证 + 微信扫码）
5. 注册成功后，在「开发」→「开发管理」→「开发设置」里找到你的 **AppID**

### 第 2 步：下载微信开发者工具

1. 打开 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载对应系统的「稳定版」
3. 安装并打开，用微信扫码登录

### 第 3 步：修改配置

1. 打开 `miniprogram/app.js`，修改：
   ```javascript
   wechatId: '你的微信号',  // 改成你的真实微信号
   ```
2. 打开 `miniprogram/project.config.json`，修改：
   ```json
   "appid": "你的小程序AppID"  // 改成你第1步拿到的AppID
   ```
3. 把你的微信二维码图片命名为 `qrcode.jpg`，放到 `miniprogram/images/` 目录（已经放了一张示例图，替换成你的就行）

### 第 4 步：导入项目

1. 打开微信开发者工具
2. 点「导入项目」
3. 目录选择 `miniprogram` 文件夹
4. AppID 填你的小程序 AppID
5. 项目名称随便填
6. 点「导入」

### 第 5 步：预览和上传

1. 导入后，在开发者工具里能看到小程序效果
2. 点工具栏「预览」，用微信扫码可以在手机上预览
3. 确认没问题后，点「上传」
4. 填写版本号和项目备注，点「上传」

### 第 6 步：提交审核

1. 打开 https://mp.weixin.qq.com 登录小程序后台
2. 点「版本管理」
3. 在「开发版本」里找到你刚上传的版本，点「提交审核」
4. 填写审核信息：
   - 服务类目：选「工具」→「信息查询」或「其他」
   - 功能页面：首页
   - 功能描述：展示微信二维码，方便用户添加客服微信
5. 提交审核，等待 1-3 天审核通过

### 第 7 步：发布并获取小程序码

1. 审核通过后，在「版本管理」→「审核版本」里点「发布」
2. 发布成功后，点「设置」→「基本设置」→「小程序码及线下物料下载」
3. 下载你的小程序码（就是那个菊花形状的码）

### 第 8 步：在抖音/小红书引流

1. 把小程序码图片发到抖音/小红书
2. 用户保存图片 → 打开微信 → 扫一扫 → 从相册选小程序码
3. 打开你的小程序 → 长按二维码识别加微信

> 注意：抖音/小红书里不能直接点击链接打开微信小程序，必须通过小程序码扫码的方式。这是目前唯一可行的跨平台引流方式。

## 目录结构

```
miniprogram/
├── app.js              # 小程序入口，配置微信号和二维码路径
├── app.json            # 小程序配置
├── app.wxss            # 全局样式
├── project.config.json # 项目配置（填AppID）
├── sitemap.json        # 站点地图
├── images/
│   └── qrcode.jpg      # 你的微信二维码（替换成你的）
└── pages/
    └── index/
        ├── index.js    # 页面逻辑
        ├── index.json  # 页面配置
        ├── index.wxml  # 页面结构
        └── index.wxss  # 页面样式
```

## 注意事项

- 个人小程序不能涉及支付、电商等功能，纯展示二维码没问题
- 审核时不要在小程序里出现"抖音""小红书"等竞品字样
- 小程序码只能用微信扫一扫识别，支付宝/其他浏览器扫不了
- 个人小程序每年有一定的免费额度，正常使用足够
